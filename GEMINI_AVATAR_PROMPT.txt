# 🎨 Промпт для Gemini - Аватар GitHub

Скопіюй і вставь в Gemini (gemini.google.com):

---

Create a professional GitHub profile avatar for a Python developer named "Solipsist".

Style: Modern, minimalist, tech-focused
Colors: Dark background (#0a0e27), neon green accent (#00ff88), cyan highlights (#0099ff)
Elements:
- Abstract geometric shapes or circuit board patterns
- Python logo or code symbols subtly integrated
- Futuristic, cyberpunk aesthetic
- Clean and recognizable at small sizes (200x200px)

The design should convey:
- Technical expertise
- Modern development
- Backend/API focus
- Trading bots and automation

Format: Square (1:1 ratio), high resolution, suitable for GitHub profile picture
No text, just visual elements

---

## Після генерації:

1. Скачати картинку
2. Обрізати до квадрату (якщо потрібно)
3. GitHub → Settings → Profile → Edit → Upload photo
4. Готово!
