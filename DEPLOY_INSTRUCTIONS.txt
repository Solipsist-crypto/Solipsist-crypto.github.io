GitHub більше не приймає паролі для git push!

ПОТРІБЕН PERSONAL ACCESS TOKEN:

1. GitHub → Settings → Developer settings
2. Personal access tokens → Tokens (classic)
3. Generate new token (classic)
4. Note: "Git push token"
5. Expiration: 90 days
6. Scope: ✅ repo (всі галочки)
7. Generate token
8. СКОПІЮЙ ТОКЕН (показується тільки раз!)
9. Використовуй замість пароля

Або простіше - використай GitHub Desktop:
- Скачати: https://desktop.github.com/
- Авторизуватись
- Перетягнути папки в GitHub Desktop
- Publish repository
