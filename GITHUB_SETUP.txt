Варіант Б (Швидко через CLI):
  1. Встановити: winget install --id GitHub.cli
  2. gh auth login
  3. gh repo list --limit 1000 --json name -q '.[].name' | xargs -I {} gh repo delete {} --yes

4️⃣  СТВОРИТИ PORTFOLIO РЕПОЗИТОРІЙ
═══════════════════════════════════════════════════════════════════════════════

1. GitHub → New repository
2. Repository name: portfolio
3. Description: My portfolio website - Python Developer
4. Public
5. Create repository

6. У терміналі:
   cd D:\My_Progect\Frilance\portfolio-site
   git init
   git add .
   git commit -m "Initial commit: Portfolio site"
   git branch -M main
   git remote add origin https://github.com/твій_username/portfolio.git
   git push -u origin main

7. Settings → Pages → Source: main branch → Save

8. Дочекатись деплою (2-5 хв)

9. Твій сайт: https://твій_username.github.io/portfolio
