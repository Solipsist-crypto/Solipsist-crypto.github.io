## ✨ Особливості

- 🎨 **Сучасний дизайн** - Темна тема з неоновими акцентами
- 📱 **Повністю адаптивний** - Працює на всіх пристроях
- ⚡ **Швидкий** - Оптимізований код, швидке завантаження
- 🎭 **Анімації** - Glitch ефекти, parallax, smooth scroll
- 🔧 **Легко запустити** - Один клік на start.bat

## 🚀 Швидкий старт

### Windows:
```bash
# Подвійний клік на start.bat
start.bat
```

Відкриється: `http://localhost:8000`

### Linux/Mac:
```bash
chmod +x start.sh
./start.sh
```
